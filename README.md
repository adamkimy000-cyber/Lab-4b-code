## Overview
This repository contains the solutions for Lab 4b, demonstrating JSON data retrieval using `fetch()` and DOM operations using jQuery 4.0.0.

---

## Files Included
- `books.json`: JSON dataset containing book items.
- `books.html`: Dynamic HTML displaying fetched JSON data.
- `jquery-dom.html`: DOM manipulation and click event handling using jQuery.

---

## How to Run
1. Open this project directory in **VS Code**.
2. Right-click `books.html` or `jquery-dom.html` and select **Open with Live Server**.
3. View the outputs in your browser at `http://127.0.0.1:5500/`.
